# sunsFamilyBill · 家庭记账

家人关注微信服务号后，在手机上对服务号发一句话就能记账：

```
2026-11-17 打车 35
```

服务号秒回确认，本月累计也一并算好。**账本服务端和全部数据都运行在自己的一台机器上**
（开发期是 Muse 办公机），数据只存本机一个 SQLite 文件 `data/family.db`，不经过任何第三方记账云。

## 用法（在服务号里发消息）

| 发什么 | 效果 |
|---|---|
| `2026-11-17 打车 35` | 记一笔：日期 事项 金额 |
| `11月17日 午饭 28` / `昨天 停车 10` / `打车 35` | 日期可简写、可省略（默认今天） |
| `收入 2026-11-15 工资 12000` | 记一笔收入 |
| `本月` | 本月汇总 + 最近几笔 |
| `今天` | 今天的账单 |
| `查 2026-10` | 查某月汇总 |
| `删除上一笔` | 撤销自己最近一笔（记错纠正） |
| `帮助` | 说明 |

同一服务还带一个网页账本（浏览器打开服务地址）：按月看账、汇总、一句话补录、删错账。

## 本地运行

零依赖，只要 Node ≥ 22（自带 SQLite 模块）：

```bash
node server.js
# 网页账本 http://localhost:4180 ，微信回调路径 /wechat
```

环境变量：

| 变量 | 说明 | 默认 |
|---|---|---|
| `PORT` | 监听端口 | `4180` |
| `WECHAT_TOKEN` | 服务号后台填的 Token，两边必须一致 | `sunsfamilybill` |
| `FAMILY_MEMBERS` | `openid=名字,openid=名字`，显示“谁记的账” | 空 |
| `WECHAT_WHITELIST` | 逗号分隔的 openid 白名单，配了之后只有家里人能记账 | 空（不限） |

测试：`node --test`

## 对接微信服务号

微信服务器只往公网 80/443 地址推送消息，本机需要一条入站隧道
（推荐 Cloudflare Tunnel，账本和数据仍只在本机，隧道只转发消息）。
完整步骤见 [docs/WECHAT_SETUP.md](docs/WECHAT_SETUP.md)。
