# sunsFamilyBill · 家庭记账

家人关注微信服务号后，在手机上对服务号发一句话就能记账：

```
2026-11-17 打车 35
```

服务号秒回确认，本月累计也一并算好。**账本服务端和全部数据都运行在自己的一台机器上**
（开发期是 Muse 办公机），数据只存本机一个 SQLite 文件 `data/family.db`，不经过任何第三方记账云。

## 用法（在服务号里发消息）

| 发什么 | 效果 |
|---|---|
| `2026-11-17 打车 35` | 记一笔：日期 事项 金额 |
| `11月17日 午饭 28` / `昨天 停车 10` / `打车 35` | 日期可简写、可省略（默认今天） |
| `收入 2026-11-15 工资 12000` | 记一笔收入 |
| `本月` | 本月汇总 + 最近几笔 |
| `今天` | 今天的账单 |
| `查 2026-10` | 查某月汇总 |
| `删除上一笔` | 撤销自己最近一笔（记错纠正） |
| `帮助` | 说明 |

同一服务还带一个网页账本（浏览器打开服务地址）：按月看账、汇总、一句话补录、删错账。

## v0.2 管理版（网页后台 + 预算）

网页账本升级为管理后台，打开服务地址先输**管理口令**登录（初始口令 `mermaid888`，
登录后可在「成员与设置」里修改；微信回调 `/wechat` 不受口令影响）：

- **全年总览**：按年看 12 个月汇总（每月花销/收入/结余/笔数 + 全年合计），点月份跳到该月账单；
- **分月账单**：上/下月一键切换，补录、删错账照旧；
- **全局搜索**：按关键字搜全部账单（事项、原始消息、成员名都可搜），带命中笔数和金额合计；
- **预算**：可设**月预算**和**全年预算**（全年 = 全年总花销上限），网页端在全年/分月视图里设置，
  年视图和月视图都会显示已用/剩余，超支标红；
- **成员改名**：「成员与设置」里列出所有记过账的家人（openid 后4位、账单数），可改成真名，
  改完后微信回复和账单列表都用新名。

微信里也能管预算：

| 发什么 | 效果 |
|---|---|
| `预算 3000` | 设置**本月**预算 ¥3000 |
| `全年预算 50000` | 设置**今年**预算 ¥50000 |
| `查预算` | 看本月预算与剩余（设了全年预算也会一并显示） |

记账成功后的回复会自动带一行预算情况：当月设了月预算就报本月剩余（月预算优先），
只设了全年预算就报全年剩余；如果这笔花超了，会明确提醒已超支多少。

## 本地运行

零依赖，只要 Node ≥ 22（自带 SQLite 模块）：

```bash
node server.js
# 网页账本 http://localhost:4180 ，微信回调路径 /wechat
```

环境变量：

| 变量 | 说明 | 默认 |
|---|---|---|
| `PORT` | 监听端口 | `4180` |
| `WECHAT_TOKEN` | 服务号后台填的 Token，两边必须一致 | `sunsfamilybill` |
| `FAMILY_MEMBERS` | `openid=名字,openid=名字`，显示“谁记的账” | 空 |
| `WECHAT_WHITELIST` | 逗号分隔的 openid 白名单，配了之后只有家里人能记账 | 空（不限） |

测试：`node --test`

## 对接微信服务号

微信服务器只往公网 80/443 地址推送消息，本机需要一条入站隧道
（推荐 Cloudflare Tunnel，账本和数据仍只在本机，隧道只转发消息）。
完整步骤见 [docs/WECHAT_SETUP.md](docs/WECHAT_SETUP.md)。
