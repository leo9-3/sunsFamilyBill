# 微信服务号对接步骤（照着做，约 15 分钟）

前提：有一个微信服务号（订阅号也能跑通第一期，用的都是被动回复）；
账本服务已经在 Muse 办公机上跑起来（`node server.js`，端口 4180）。

## 1. 在办公机上开公网隧道（让微信能找到本机服务）

微信只往公网 80/443 地址推送消息，本机没有公网入口，所以先开 Cloudflare Tunnel：

```bash
# 快速隧道（临时地址，适合先跑通验证）
cloudflared tunnel --url http://localhost:4180
# 输出里会有一行 https://xxxx.trycloudflare.com —— 这就是你的公网地址
```

正式长期用：把一个域名托管到 Cloudflare 后建命名隧道，地址固定不变，
再把 cloudflared 装成系统服务开机自启（隧道断开期间的消息微信不会补投）。

## 2. 定一个 Token

自己想一个 3–32 字符的字符串（例如 `sunsbill2026`），两个地方要填得**一字不差**：

- 办公机启动服务前：`WECHAT_TOKEN=sunsbill2026 node server.js`
- 微信后台（下一步）

## 3. 在微信后台填服务器配置

微信开发者平台 → 我的业务 → 公众号 → 消息与事件推送（旧入口：公众号后台
设置与开发 → 基本配置 → 服务器配置）：

| 项 | 填什么 |
|---|---|
| URL | `https://xxxx.trycloudflare.com/wechat`（第 1 步的地址 + `/wechat`，必须是 443 且不带端口号） |
| Token | 第 2 步定的字符串 |
| EncodingAESKey | 点“随机生成”即可（明文模式下用不上，先记下来） |
| 消息加解密方式 | **明文模式**（先跑通；跑通后再切安全模式，需要在服务端补 AES 解密） |

点提交：微信会立刻向 URL 发一个 GET 验证请求，本服务验签通过会自动应答，
后台显示配置成功即打通。**顺序别反**：先启动服务和隧道，再点提交。

注意：启用服务器配置后，公众号后台自带的自动回复/自定义菜单会失效，之后都由本服务接管（关注欢迎语本服务已实现）。

## 4. 试记一笔

用家人微信关注服务号，发：

```
2026-11-17 打车 35
```

正常会秒回：

```
✅ 已记账（家人）
日期：2026-11-17
事项：打车
花销：¥35.00
2026-11 累计花销：¥35.00（1 笔）
```

再发 `本月` 看汇总，发 `帮助` 看全部用法。

## 5. 把家人加进来（成员名 + 白名单）

每个关注者在本服务眼里是一个 openid。让家人各发一笔账，从服务端日志/数据库
`bills.openid` 能看到各自的 openid，然后在启动环境变量里配：

```bash
FAMILY_MEMBERS="oXXXX=爸爸,oYYYY=妈妈" \
WECHAT_WHITELIST="oXXXX,oYYYY" \
WECHAT_TOKEN=sunsbill2026 node server.js
```

配了白名单后，非家庭成员发消息只会收到“未加入家庭名单”的提示，不会记账。

> 涉及主动发消息（客服消息）时才需要 AppSecret，并要把办公机的出口公网 IP
> 加进公众号的 IP 白名单；第一期只用被动回复，不需要 AppSecret。
